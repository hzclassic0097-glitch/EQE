## 🌟 Key Highlights & Academic Offerings

### 1. Quranic & Islamic Sciences
* **Holy Quran with Proper Tajweed**: Master Makharij-ul-Huroof (articulation points), Ghunnah, Qalqalah, and Noon/Meem Sakinah rules.
* **Nazra Quran for Beginners**: Noorani & Madani Qaida, Arabic phonetics, and fluid reading for children and adult beginners.
* **Hifz-ul-Quran (Memorization)**: Comprehensive memorization tracking (Sabaq, Sabqi, and Manzil) guided by certified Huffaz.
* **Basic Islamic Education**: Daily Salah/Namaz with translation, 6 Kalimas, Masnoon Duas, and Islamic manners (Akhlaq).
* **Complete Quran Program**: Comprehensive yearly curriculum integrating recitation, memorization, and Islamic knowledge.
* **Dedicated Female & Male Faculty**: Certified female scholars available for female students, teenage sisters, and young children.

### 2. Modern Academic & Professional Skills
* **Computer Skills & Tech**: Microsoft Office suite (Word, Excel, PowerPoint), Programming fundamentals (Python, Web Development), and UI/UX design.
* **Spoken English & IELTS Preparation**: Accent improvement, fluency training, and IELTS Academic/General Band 7+ prep.
* **Academic Tutoring Across All Levels**:
  * Primary & Middle School Support
  * Matriculation & Intermediate (FSc / FA / ICS)
  * Cambridge O Level & A Level Tutoring
  * University Entry Test Preparation (MDCAT, ECAT, SAT)
  * University Level Coursework Tutoring

## 🚀 How to Run Locally

1. **Direct Browser Preview**:
   Simply double-click `index.html` to open the website directly in any modern browser (Chrome, Edge, Firefox, Safari).

2. **Using a Local Server (Node.js)**:
   ```bash
   # From the project root:
   npx serve .
   ```
   Or using Python:
   ```bash
   python -m http.server 8000
   ```
   Then open `http://localhost:8000` in your browser.
